# Qembert Studio — site GitHub Pages

Site statique prêt pour GitHub Pages.

## Structure

- `index.html` — Accueil
- `applications/index.html` — Applications
- `confidentialite/index.html` — page centrale de confidentialité
- `confidentialite/opustempo/index.html` — politique de confidentialité OpusTempo
- `contact/index.html` — Contact
- `mentions-legales/index.html` — Mentions légales
- `assets/style.css` — style commun
- `assets/opustempo-icon.png` — icône OpusTempo

## Avant publication

Remplacer dans les pages :

- l'identité légale du responsable du traitement ;
- l'adresse légale ;
- l'adresse e-mail de contact ;
- les informations d'hébergement dans les mentions légales.

La politique OpusTempo contient volontairement une section distincte pour Google Play Billing : elle devra être finalisée uniquement lorsque le Premium sera effectivement intégré dans l'application.

## GitHub Pages

Si le dépôt est `USERNAME.github.io`, l'accueil sera directement à :
`https://USERNAME.github.io/`

Pour un dépôt de projet, utiliser l'URL de projet correspondante :
`https://USERNAME.github.io/NOM-DU-DEPOT/`

Les liens internes sont relatifs pour fonctionner dans les deux cas.
